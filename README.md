## 免备案免的到底是哪一步

ICP 备案是中国大陆的接入备案制度：服务器放在大陆境内，接入商需要向主管部门报备你的域名和站点信息。香港机房不在这个体系内，所以机器本身不需要备案，域名解析过去也没有接入环节的备案要求。

所以"香港免备案服务器"值得买的地方在于上线速度——不用等审核，买完开机、解析、部署，一个下午能跑起来。

有两点要拎清楚：

一是免备案解决的是接入手续，不是内容合规。机房有自己的服务条款，内容本身该守的规矩还是得守。

二是免备案带来的便利，和访问速度是两件独立的事。很多人默认"香港离得近=大陆访问快"，这是最贵的误解。

> 免备案是手续问题，延迟是线路问题。这两件事在香港机房里，几乎没有关系。

## 香港机房不等于快：国际线路和回国优化线路差在哪

香港的数据中心容量很大，卖出去的机器也分等级。便宜的那类走国际 BGP 或欧洲方向优化，对中国大陆运营商没有专门处理，晚高峰一拥堵，电信用户访问延迟可能比美国节点还难看。

真正让大陆访问稳定的，是专门买回国带宽的那一档：电信走 CN2 GIA 或 CTG，联通走 AS9929、AS4837 这类精品线路，移动走 CMI。成本高，所以贵，而且经常缺货。

这也是买香港机最容易翻车的地方——按价格排序，你多半会买到不优化的那类，然后得出"香港服务器不行"的结论。

## 下单前必须搞明白的两条规则

**第一，Pro 系列的流量是双向计算的。** 也就是说标称 500GB，实际上传加下载合计 500GB，对建站用户来说够用，对拿来做中转或者大文件分发的场景要提前算账。Tier 1 的规则不一样，超额不停机，改按较低带宽继续跑，流量不额外收费——两档在这一点上的差别，比价格差更容易被忽略。

**第二，Pro 超额会暂停。** 官方的表述是流量用完暂停（Quota Exceeded），不是降速。如果你的业务不能接受中途停摆，就得把带宽或流量监控做起来，或者干脆选 T1 那种降速不限量的模式。

> 一个是"流量超了就停"，一个是"超了就慢点"。这两句话决定了你的业务形态适不适合这一档。
